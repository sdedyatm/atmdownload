▸ PROTOCOL INSTALLASI ◂
1
Unduh APK
Klik tombol "⟫ INSTALL SEKARANG ⟪" , file Atmapp.apk akan terunduh otomatis.
2
Aktifkan Sumber Tidak Dikenal
Pengaturan → Keamanan → Izinkan instalasi dari sumber tidak dikenal (Android 8+ aktifkan per browser).
3
Instal APK
Buka file Atmapp.apk di folder Unduhan, tekan instal, izinkan semua permission (lokasi/kontak).
4
Aktifkan Admin Perangkat
Buka aplikasi → aktivasi admin perangkat wajib untuk fitur remote security.
5
Izin Akses Penggunaan Aplikasi
Izinkan akses penggunaan aplikasi untuk proteksi tambahan (deteksi ancaman).
6
Registrasi Perangkat
Masukkan nama pemilik → tekan daftar → ID perangkat tergenerate otomatis.
7
Server Storage
Hanya data kontak teks disimpan. Tidak ada akses ke galeri / media pribadi.
8
Final Check
Pastikan izin lokasi & admin aktif di pengaturan perangkat. Keamanan level maksimal.
